## File Descriptions

### 1. `QP_func_approx.py`
The main script for the Neural QP Solver. It trains different neural architectures to approximate the optimal solution $x^\star$ of a Quadratic Program (QP) given its parameters ($A, b, C, d$).

### 2. `run_all_QP_experiments.sh`
A shell script to generate results for multiple configurations. It iterates over different problem sizes ($n, m$), layers, and heads.

### 3. `analyze_QP_results.py`
A utility script to parse the logs/results generated by `QP_func_approx.py` and compute summary statistics like $R^2$ scores.
**Usage:** `python analyze_QP_results.py <n> <m>`

### 4. `covariance_experiment.py`
Dedicated script for **Appendix I**.

## Reproduction Guide

### 1. Neural QP Solver (Section 4)
To train a `LinearTransformer` on the standard $n=5, m=3$ QP task:
```bash
python QP_func_approx.py \
    --model_type LinearTransformer \
    --n 5 --m 3 \
    --num_layers 8 --num_heads 2
```

To reproduce results for higher dimensions (e.g., $n=20, m=8$):
```bash
python QP_func_approx.py \
    --model_type LinearTransformer \
    --n 20 --m 8 \
    --num_layers 8 --num_heads 2 \
    --num_train 100000 \
    --num_val 20000 --num_test 20000
```

### 2. Distribution Shift (Section 4)
To test robustness against ill-conditioned matrices (distribution shift), specify the condition number range $\kappa$:
```bash
# Train on specific condition number range [10, 20]
python QP_func_approx.py \
    --model_type LinearTransformer \
    --n 5 --m 3 \
    --kappa_low 10 --kappa_high 20
```

### 3. Architectural Ablation (Appendix D)
To compare Transformers against MLP and LSTM baselines:
```bash
# MLP Baseline
python QP_func_approx.py --model_type MLP --n 5 --m 3

# LSTM Baseline
python QP_func_approx.py --model_type LSTM --n 5 --m 3
```

### 4. Negativity Case: Parity Barrier (Appendix G)
To run the covariance learning experiments:

```bash
python covariance_experiment.py --model_type LinearTransformer
```

```bash
python covariance_experiment.py --model_type BasicLinearTransformer
```
